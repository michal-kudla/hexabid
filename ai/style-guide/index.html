Hexabid Style Guide

Jedno źródło prawdy dla tokenów, komponentów i wzorców UI. Paleta Concept B (Warm Professional) z wzmocnioną dostępnością (WCAG AA). Wszystkie kontrasty tekst-vs-tło spełniają 4.5:1.

2. Contrast Verification (WCAG AA)

Każda para tekst-vs-tło musi spełniać 4.5:1 (normal) lub 3:1 (large text).
